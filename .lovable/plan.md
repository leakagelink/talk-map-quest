# Build the AI navigation mobile prototype

## Experience
- Create a phone-first, dark map experience with a distinctive cyan-lime navigation accent, subtle depth, crisp typography, and restrained glass surfaces.
- Use a stylized map illustration as the persistent visual foundation, with clear demo-data labeling and no claims of live GPS or traffic.
- Add smooth, reduced-motion-aware transitions and touch-sized controls throughout.

## Product flow
- Build an interactive launch, three-step onboarding, and privacy-first location explanation.
- Connect the core journey: home map → search → destination → route comparison → active navigation → trip complete → trip detail → cinematic replay.
- Add AI assistant, live trip metrics, trip history, AI trip insights, profile, settings, and privacy/location controls.
- Keep primary navigation available across the main areas and use bottom sheets for map actions.

## Reusable system
- Create modular map, cards, route selector, AI message/input, metrics, trip cards/timeline, bottom sheet/navigation, permission, status, and button primitives.
- Centralize realistic Indore demo places, routes, journeys, and analytics.
- Keep the data boundary explicit so real routing, GPS, and tracking services can replace mock adapters later.

## Validation
- Add unique page metadata.
- Verify the primary flow and visual layout at mobile dimensions, including interactive controls and screen transitions.
- Check the preview for build, runtime, console, overflow, and accessibility issues.
